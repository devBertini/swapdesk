# Code of Conduct

This project follows the Contributor Covenant, version 2.1. The full text is published at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project (issues, pull requests, discussions and any other space it runs) you agree to follow that code of conduct. In short: be respectful, accept constructive feedback, focus on what is best for the community, and do not harass or demean anyone.

## Enforcement

Report unacceptable behavior with GitHub's **Report content** option on the comment, issue, pull request or discussion (the "..." menu), choosing to report it to the repository maintainers. All reports are reviewed and handled with respect for the privacy of the reporter.

Enforcement follows the guidelines in the Contributor Covenant 2.1 linked above.
